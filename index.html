Cómo usar
Pasos simples
  1. Apretá "Copiar snapshot para IA".
  2. Abrí claude.ai (o la app de Claude) en una conversación nueva.
  3. Pegá (Ctrl+V). El prompt ya viene armado con tono argentino y la estructura de informe.
  4. Claude te devuelve el análisis: lectura general, alertas, estructura de costos, blanca vs negra, recomendaciones.

El análisis es una lectura, no una verdad absoluta. Claude no conoce el contexto externo (mercado, clientes, decisiones pasadas), solo lo que está en el Excel.

Flujo de fondos

—

De dónde sale cada rubro

Ventas 1: facturas de Seguimiento Cobranzas menos notas de crédito. Ventas 2: cobros de Caja 2. Compras, Energía, Transporte, Otros, Servicios: facturas de proveedores cargadas en Cheques, según el rubro de cada proveedor; van al circuito 2 si el proveedor termina en "C2" o se pagaron con una OP de Caja 2. Mantenimiento: app Mantenimiento (B → 1, N → 2). Mano de obra: Horas › Control mensual (recibos → 1, por fuera y vales → 2). Impuestos 1: el % fijo sobre Ventas 1, como en el Excel. Lo que falta se completa en "Cargas manuales" (m = cargado a mano).
